### 👋 About Me

I'm an **operator-developer** in **Singapore** 🇸🇬 — I run a multi-outlet F&B group *and* build its full software stack with a tiny engineering team. I sit on **three Aeroplus group boards** (hospitality, spirits distribution, AI software), and I have **one exit** behind me.

- 🏗️ Co-led **EASI** as primary engineer — a 6-sub-project B2B/B2C spirits-commerce platform, rebuilt by **2 developers** to replace a product that took a **~20-person team**
- 🍷 Migrated restaurant operations off Excel/VBA into **custom apps, solo** — scheduler, incentive program, CMS
- ✈️ Designing a **phased AI/ERP** for the group's HK/China aviation parts-trading arm
- 🤖 AI-assisted, end to end — Claude Code agent harnesses, OCR pipelines, and self-hosted local LLMs
- 🌏 Bilingual **EN / ZH**, cross-border ops across **SG → HK → China**
- 💙 **Building has always been my first love** — operating just gave it a P&L
